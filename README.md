# 名古屋 天気・潮汐ダッシュボード

名古屋市と周辺6か所の釣りスポットの午前・午後・明日の天気予報、名古屋市の今日の日の出・日の入り、名古屋港の今日・明日の潮汐を1画面で確認できる静的Webアプリです。iPhoneではホーム画面へ追加し、アプリのように起動できます。
仕様と設計の正本は [`SPEC.md`](./SPEC.md) です。

## iPhoneで使う

公開URLは次のとおりです。

```text
https://ayuko66.github.io/weather-and-tide/
```

1. iPhoneのSafariで公開URLを開く
2. Safariの共有ボタンをタップする
3. 「ホーム画面に追加」を選ぶ
4. 追加された「名古屋 空と海」アイコンから起動する

天気・潮汐は公開APIから取得するため、最新情報の表示にはインターネット接続が必要です。オフライン利用、App Store配布、通知、バックグラウンド更新には対応していません。

## ローカルで起動する

依存パッケージやビルドは不要です。`index.html` をブラウザで直接開いてください。

```text
index.html
├── style.css
├── app.js
├── manifest.webmanifest
└── icons/
```

PWA関連ファイルをHTTP経由で確認する場合は、Dockerで静的Webサーバーを起動します。

```sh
docker run --rm -p 8080:80 -v "$PWD:/usr/share/nginx/html:ro" nginx:alpine
```

起動後、`http://localhost:8080/` をブラウザで開いてください。iPhoneのホーム画面追加を本番同様に確認するには、HTTPSのGitHub Pagesを使用します。

Open-Meteo と tide736.net の公開APIへブラウザからアクセスするため、表示にはインターネット接続が必要です。各カードは独立しており、一部のAPIでエラーが発生しても他のカードは表示されます。

公開直後に古い表示が残る場合は、Safariでページを再読み込みしてください。CSSとJavaScriptには更新時に変更するバージョン番号を付け、古いファイルがブラウザキャッシュから読み込まれ続けることを防止しています。

選択できる地点は、新舞子マリンパーク、りんくう釣り護岸、四日市港・霞地区魚釣り施設、碧南釣り広場、稲永公園周辺、武豊緑地です。現地では立入禁止・釣り禁止の表示や施設の利用時間を必ず確認してください。

## 動作確認

1. Dockerの静的WebサーバーまたはGitHub Pagesでページを開く
2. 天気カードに午前9時、午後3時、明日の天気・気温・降水確率・風速と、今日の日の出・日の入り時刻が表示されることを確認する
3. 潮汐カードに今日・明日それぞれの潮名、満潮・干潮の時刻と潮位が表示されることを確認する
4. 釣りスポットを選択し、その地点の午前9時、午後3時、明日の予報が表示されることを確認する
5. iPhoneのSafariからホーム画面へ追加し、専用アイコンとstandalone表示を確認する
6. 通信を切って再読み込みし、3つのカードに個別の日本語エラーが表示されることを確認する

詳細なAPI仕様、画面仕様、エラー処理は [`SPEC.md`](./SPEC.md) を参照してください。
